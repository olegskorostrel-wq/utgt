# Расписание 11-А УТЖТ

## Что уже работает
- `data/schedule_11A.json` — базовое расписание 11-А по дням (из присланного PDF)
- `data/bells.json` — реальное время звонков (пн отличается от вт-сб)
- `scraper.py` — парсит https://utgt-pgups.ru/zamena-urokov.html, достаёт
  дату + ссылку на картинку замены (или "по расписанию", если замен нет).
  Логика проверена на фикстуре, повторяющей реальную структуру страницы.
- `today_agenda.py` — склеивает расписание + звонки + статус замены на
  сегодня, печатает агенду в консоль

## Как запустить
```
pip install requests beautifulsoup4
python3 today_agenda.py
```
Я не смог прогнать scraper.py живьём на utgt-pgups.ru — из песочницы
Claude нет доступа к произвольным сайтам (только pypi/github и т.п.).
Логику проверил на фикстуре-копии реальной HTML-структуры — она верна,
но перед тем как полагаться на скрипт, прогони его один раз сам и
сверь вывод с сайтом глазами.

## Главное ограничение: замены — это картинки, не текст
Скрипт сейчас **не читает содержимое** картинки замены — только находит
её и даёт ссылку. Это и есть MVP ("вариант A" из чата): сайт покажет
твоё расписание с реальным временем + подсунет картинку замены, чтобы
сверить глазами.

## V2 — если захочешь автоматический разбор замен
Нужно прогнать картинку через vision-модель (например Claude API с
image input) с промптом вида "найди строки с группой 11-А, верни JSON".
Потребуется:
- свой API-ключ Anthropic (или другой vision-OCR сервис)
- обработка случаев, когда скан кривой/нечитаемый — нужен fallback
  "не смог разобрать, смотри картинку сам"

## Деплой (чтобы это крутилось само каждый день)
Внутри чата с Claude сервер не живёт вечно — сессия сбрасывается.
Варианты бесплатного автозапуска:
- **GitHub Actions по расписанию (cron)** + статическая страница
  (GitHub Pages) — самый простой вариант, ничего не платишь
- Маленький VPS/свой ПК с cron — если хочешь держать это у себя

Удобнее всего дальше вести разработку (деплой, автозапуск, правки) в
Claude Code — это desktop-приложение умеет сразу гонять и выкладывать
такие проекты.
