# Расписание УТЖТ

Сайт: **https://raspisanie-utgt.github.io/**

Статический сайт: расписание любой из 19 групп очного отделения на сегодня, завтра и неделю
с реальным временем звонков, с учётом замен и с картинкой распоряжения о замене.
При первом заходе открывается выбор группы, выбор запоминается; ссылка `?group=21-С` открывает
нужную группу сразу. «Я преподаватель» — расписание преподавателя по всем группам (`?teacher=`).

## Откуда данные

| Файл | Источник |
|---|---|
| `data/groups/*.json` | [Расписание учебных занятий, 1 семестр 2026/2027](https://utgt-pgups.ru/raspisaniya-i-grafiki.html) (PDF), все 19 групп — `tools/extract_schedule.py`, сверены вручную |
| `data/calendar.json` | Календарный учебный график: каникулы, практики, сессии, праздники — `tools/extract_calendar.py` |
| `data/bells.json` | [Расписание звонков 2026/2027](https://utgt-pgups.ru/raspisaniya-i-grafiki.html) (PDF) |
| `data/zameny/` | [Замена уроков](https://utgt-pgups.ru/ochnoe-zaochnoe-otdelenie/58-zamena-zanyatij.html), обновляет `scraper.py` |

**Недели.** Расписание чередуется: 1-я / 2-я неделя. В PDF это ячейка, разделённая на две строки:
верхняя — 1-я неделя, нижняя — 2-я, предмет идёт на всю пару (у 11-А: пятница и суббота, 3-я пара).
Номер недели считается от `week_anchor` в расписании группы (19.10.2026 — 1-я неделя),
а если в распоряжении о замене написано «N-я неделя», берётся оттуда.

## Как это работает

1. `scraper.py` скачивает страницу замен, находит блоки «на DD месяца YYYY года / очное отделение»
   и скачивает картинки.
2. Замены публикуются **картинкой**, поэтому скрипт ищет сетку таблицы и распознаёт каждую ячейку
   через tesseract (русский). Строки всех групп сохраняются в `data/zameny/<дата>.json`.
   Если распознавание сомнительное, сайт об этом предупреждает. Картинка показывается всегда.
3. `site/agenda.js` в браузере накладывает замены на обычное расписание и звонки
   и подсвечивает текущий и следующий урок (время московское).
4. GitHub Actions (`.github/workflows/update.yml`) запускается каждый час с 06:47 до 21:47 МСК,
   сохраняет новые замены коммитом и деплоит сайт на GitHub Pages.

Замены обычно выкладывают **накануне**, поэтому сайт хранит их за последние 21 день,
и «сегодняшние» замены остаются видны, даже когда на сайте УТЖТ уже висят завтрашние.

## Локально

```bash
sudo apt install tesseract-ocr tesseract-ocr-rus
pip install -r requirements.txt
python scraper.py                  # проверить сайт и обновить data/zameny
python scraper.py --ocr картинка.png   # распознать одну картинку
python today_agenda.py             # расписание на сегодня в консоли (или: today_agenda.py 2026-10-24)
python build_site.py && python -m http.server -d _site 8000
python -m pytest tests -q && node --test tests/agenda.test.js tests/calendar.test.js tests/teachers.test.js
```

Посмотреть любой день: `index.html?group=11-А&date=2026-10-24`.

Данные расписания 11-А и звонков совпадают с присланными исходными файлами
(проверено программно), формат приведён к одному для сайта и консоли.

## Когда начнётся новый семестр

Прогоните `tools/extract_schedule.py` и `tools/extract_calendar.py` по новым PDF, обновите `data/bells.json`.

## Все группы

- `tools/extract_schedule.py` извлекает расписание **всех 19 групп** очного отделения из PDF
  по сетке таблицы → `data/groups/<группа>.json` (+ `index.json`). Все группы сверены вручную
  (`"verified": true`).
- `scraper.py` сохраняет замены по всем группам: поле `all_changes` в `data/zameny/<дата>.json`.
  `python scraper.py --reprocess` заново распознаёт уже скачанные картинки.
- `tools/check_data.py` — проверка данных: опечатки в названиях и инициалах, накладки пар,
  один кабинет у двух пар, преподаватель в двух местах, странные кабинеты, сомнительные замены,
  номер недели в распоряжениях. Запускается при каждой автопроверке (отчёт в логе),
  явные ошибки ломают тесты. Опечатки PDF (перестановки букв, инициалы, точка после кода МДК)
  `extract_schedule.py` исправляет сам и пишет, что исправил.
- Архив замен за всё время — `data/archive/` (`python tools/archive.py --show 21-С`).

```bash
python tools/extract_schedule.py путь/к/расписанию.pdf
```

## Обратная связь через Telegram-бота → задачи GitHub

`tools/tg_feedback.py` + `.github/workflows/feedback.yml`: каждые 15 минут забирает новые
сообщения из бота и создаёт по каждому задачу с меткой `telegram`. Явный спам (ссылки,
реклама, капслок) получает метку `возможно спам`, и бот такому отправителю не отвечает.
В задачу попадают только текст и имя — без @username и id чата (репозиторий публичный).

Подключение: создать бота у @BotFather и добавить его токен в секрет репозитория
`TELEGRAM_BOT_TOKEN` (Settings → Secrets and variables → Actions). Без секрета запуск просто пропускается.

**Ответы людям.** Закрыть задачу как «Close as completed» — бот напишет автору, что всё исправлено.
Комментарий в задаче `/ответ текст` (только от владельцев) — бот перешлёт текст автору.
Закрытие как «not planned» (спам) — бот молчит. Id чата хранится в задаче зашифрованным
ключом из токена бота; после `/revoke` старым авторам ответить уже не получится.

## Учебный график и новости

- `tools/extract_calendar.py` — календарный учебный график (КУГ) из PDF техникума → `data/calendar.json`:
  праздники, каникулы, сессия с экзаменами, практика, сборы — для всех 19 групп.
  На сайте: строка «До каникул N дней», выходные в праздники и каникулы, отсчёт до сессии за 45 дней.
- `tools/news.py` — последние новости с utgt-pgups.ru → `data/news.json`, обновляется вместе с заменами;
  на сайте — раскрывающийся блок «Новости техникума».

**Преподаватели.** `tools/teachers.py` берёт полные ФИО из PDF «Педагогический состав» на сайте УТЖТ →
`data/teachers.json`. На сайте: нажать на урок — полное имя и «как обращаться».

**Полезное.** `data/info.json` — учебная часть (часы работы, телефон), ссылки (СДО, ВК), документы по курсам
(индивидуальный проект, курсовые, ВКР) и программы ГИА по специальностям. На сайте — свёрнутый блок «Полезное»
со статусом «Открыто / Обед / Закрыто, откроется …». На компьютере вместо блоков «Где преподаватель» и
«Полезное» справа плитки с иконками и живыми подписями (звонки, учебная часть, кабинеты по этажам и др.) —
каждая открывает своё окно (`drawTiles` и `openPanel` в `app.js`). В графике (`calendar.json`) для каждой группы также
специальность, курсовые работы и названия практик по условным обозначениям.

**Мониторинг.** `tools/health.py` после каждой проверки ведёт счётчик неудач подряд (`data/health.json`).
3 неудачи подряд (≈ 6 часов) — открывается задача с меткой «сбой», назначенная владельцу (пуш в приложении
GitHub); после первой успешной проверки она закрывается сама. Страница без замен очного отделения
(поменялась вёрстка) тоже считается сбоем.
